## OBS

- This document speficies a guide for remote connection to OBS Websocket to enable moderators/producers to control streams over the internet.

## Steps

1. Create a Cloudflare account [here](https://cloudflare.com).
2. Contact sales team @[streamkit](contact@streamkit.fun) to get your CNAME record. Ex. `streamer.streamkit.fun`
3. Get credentials.
